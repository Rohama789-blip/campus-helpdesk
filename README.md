# 🎓 Campus Helpdesk

A web-based campus issue reporting system that helps students report campus-related problems and makes it easier to manage and track reported issues.

## 🌐 Live Demo

**[Visit Campus Helpdesk](https://campus-helpdesk-wheat.vercel.app/)**

## 📌 About the Project

Campus Helpdesk is designed to provide a centralized platform for reporting campus issues. It aims to improve communication between students and campus administration by making issue reporting more organized and accessible.

## ✨ Features

- 📝 Report campus-related issues
- 🏫 Simple and user-friendly interface
- 📋 Organize and manage issue reports
- 🌐 Access the application through a web browser
- 📱 Responsive interface, depending on the implemented design

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Build Tool:** Vite
- **Code Quality:** ESLint
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Rohama789-blip/campus-helpdesk.git
```

### 2. Navigate to the project folder

```bash
cd campus-helpdesk
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.

## 🏗️ Build for Production

Run the following command to create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
